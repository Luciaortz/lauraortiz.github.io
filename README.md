#  Días Festivos en Colombia

Aplicación web desarrollada con HTML que permite consultar información relacionada con los días festivos en Colombia mediante una interfaz sencilla y de fácil acceso.

---

##  Descripción

Días Festivos en Colombia es un proyecto web diseñado para mostrar información sobre los festivos nacionales del país. La aplicación ofrece una interfaz simple y accesible para consultar fechas importantes del calendario colombiano.

Este proyecto fue desarrollado como práctica de desarrollo web, aplicando conceptos básicos de estructura de páginas web y organización de contenido mediante HTML.

---

##  Características

* Consulta de días festivos en Colombia.
* Interfaz web sencilla e intuitiva.
* Acceso rápido a la información.
* Ejecución directa desde el navegador.
* Diseño ligero y fácil de mantener.

---

## 📋 Requisitos Previos

Para utilizar la aplicación solo necesitas:

* Un navegador web moderno.
* Conexión a internet (si el proyecto consume recursos externos).

---

##  Instalación

### 1. Clonar el repositorio

```bash
git clone https://github.com/usuario/Dias-festivos-en-colombia.git
```

### 2. Acceder al directorio del proyecto

```bash
cd Dias-festivos-en-colombia-master
```

### 3. Abrir la aplicación

Abrir el archivo:

```text
index.html
```

en cualquier navegador web.

---

##  Ejecución

La aplicación puede ejecutarse simplemente abriendo el archivo:

```text
index.html
```

o utilizando una extensión como **Live Server** en Visual Studio Code.
